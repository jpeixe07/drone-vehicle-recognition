# Reference gallery

This replaceable starter gallery contains **83 simulation-derived vehicle crops**, including augmented variants, grouped by the canonical labels in `configs/classes.yaml`.

The initial images were generated by flying a simulated drone over 3D models of the five target vehicles. Vehicle detections were cropped from those simulated aerial observations and organized by model label. Real-flight footage of the target vehicles is not required to construct this initial gallery.

| Label | Images |
| --- | ---: |
| `arquus_vt4` | 30 |
| `panhard_vbl` | 13 |
| `renault_ccfm` | 8 |
| `renault_gbc180` | 13 |
| `vltt` | 19 |

Files containing `_aug_` are augmented variants rather than independent observations. Keep these relationships when reviewing references or designing experiments. There are no category groups.

To replace or extend references, place RGB vehicle crops in the appropriate class directory and rebuild the reference index once indexing is implemented. Changes to the gallery, extractor checkpoint, or preprocessing invalidate an existing index.

These files support recognition from simulated references. The real forest-flight evaluation images belong in `data/forest_vehicles/` and must remain independent of gallery selection and calibration. Their role is to measure how robustly the approach transfers from simulated views to real aerial observations.

See the [main README's vehicle illustrations](../../README.md#demonstration-vehicles-and-simulated-references) for visual examples of the five vehicle types. Those illustrations are documentation assets, separate from these simulated aerial crops.
